# Creator-AI Frontend (Demo)

This is a demo frontend (Next.js + Tailwind + Framer Motion) for Creator-AI.

## Deploy (mobile -> Vercel)
1. Create GitHub repo `creator-ai-frontend`.
2. Add these files in the repo (copy-paste on mobile).
3. Go to Vercel -> Import Project -> connect repo -> Deploy.

No backend yet — wallet and tool flows are local demo. Next: integrate Supabase/FastAPI for real auth/payments.
